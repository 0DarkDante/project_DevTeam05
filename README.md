**Booksy** — лендінг для презентації продукту, реалізований за макетом Figma. Сторінка знайомить відвідувачів із пропозицією Booksy та веде до цільової дії. Фронтенд написано на JavaScript, для локальної розробки та збірки використано Vite.

## Використання

Booksy запускається як окремий сайт. Щоб переглянути версію, підготовлену до публікації, встановіть залежності за інструкцією нижче та виконайте:

```sh
npm run build
npm run preview
```

Відкрийте адресу, яку Vite виведе в терміналі. Режим `preview` призначений для локального перегляду збірки.

## Розробка

### Вимоги

Для роботи з репозиторієм потрібні Git, Node.js і npm. Використовуйте версію Node.js, зазначену в `.nvmrc` або `package.json`, якщо вона задана. Інакше перевірте вимоги встановленої версії Vite.

### Встановлення залежностей

Клонуйте репозиторій або відкрийте передану копію проєкту. У кореневому каталозі виконайте:

```sh
npm install
```

### Запуск сервера розробки

```sh
npm run dev
```

Відкрийте адресу з термінала. Типовий порт Vite — `5173`.

### Створення збірки

```sh
npm run build
```

## Тестування

Для приймання та перевірки після оновлень відкрийте зібрану версію через `npm run preview` і пройдіть короткий чекліст.

- Звірте сторінку з макетом Figma на мобільному й десктопному екранах.
- Перевірте переходи за посиланнями, навігацію та кнопки.
- Переконайтеся, що зображення й шрифти завантажуються, а консоль браузера не показує помилок під час основних дій.
- Перевірте, що `npm run build` завершується без помилок.


## Contributing

Помилки та пропозиції щодо змін можна оформити в **Issues** репозиторію. Для помилки вкажіть кроки відтворення, очікуваний і фактичний результат. Якщо проблема в оформленні, додайте скриншот і ширину екрана.

Зміни готуйте в окремій гілці. Перед відкриттям **Pull Request** перевірте збірку, стисло опишіть зміни й додайте інструкцію з перевірки. Для візуальних змін додайте скриншоти.

## FAQ

### Чим відрізняються `npm run dev` і `npm run preview`?

`dev` запускає сайт із вихідних файлів і показує зміни під час розробки. `preview` показує вже зібрану версію, яку можна перевірити перед публікацією.
