# 📚 Booksy — Online Bookstore

**Booksy** — сучасна адаптивна онлайн-книгарня, створена командою **BookCraft**
для людей, які люблять читати, відкривати нові книги та цікавляться
літературними подіями.

Проєкт об'єднує каталог книг, відгуки читачів, інформацію про книжкові заходи та
контактні дані в одному зручному вебінтерфейсі.

## 🎯 Мета проєкту

Мета Booksy — зробити пошук книг та ознайомлення з літературними новинками
простим, швидким і доступним.

Сайт допомагає користувачам:

- Переглядати каталог книг за категоріями.
- Ознайомлюватися з описами та цінами книг.
- Читати відгуки інших покупців.
- Дізнаватися про літературні заходи та реєструвати зацікавленість у них.
- Переглядати тематичні матеріали про книги та читання.
- Знаходити контактну інформацію книгарні.

## 🛠 Технології

Для розробки використано:

- **HTML5** — семантична структура вебсторінки.
- **CSS3** — стилізація, адаптивна верстка та медіазапити.
- **JavaScript (ES6+)** — інтерактивність, слайдери, модальні вікна та обробка
  подій.
- **Vite** — локальний сервер розробки та збірка проєкту.
- **Swiper.js** — реалізація інтерактивного слайдера відгуків.
- **Git / GitHub** — контроль версій та спільна розробка.
- **GitHub Projects** — планування завдань і відстеження прогресу.
- **Figma** — дизайн-макет та основа для верстки.

## ✨ Основні можливості

### Header & Navigation

Адаптивна навігація з мобільним меню та якірними посиланнями для швидкого
переходу між секціями.

### Hero

Інтерактивний слайдер із чотирма рекламними банерами, спеціальними пропозиціями
та переходами до каталогу книг.

### Books & Book Modal

Каталог книг із категоріями, зображеннями, назвами та цінами. Модальне вікно
дозволяє переглянути детальну інформацію про вибрану книгу.

### Customer Feedbacks

Слайдер із відгуками читачів, реалізований за допомогою Swiper.js.

### Events & Contact Modal

Інформація про літературні заходи з можливістю відкрити форму реєстрації.

### Booksy Cozy Corner

Інформаційна секція з тематичним контентом про літературу та читання.

### Location

Контактна інформація, адреса книгарні та інтегрована карта Google Maps.

### Footer

Додаткова навігація, контактна інформація та форма підписки на розсилку.

## 🚀 Локальний запуск

### Вимоги

Перед запуском переконайтеся, що встановлено:

- Node.js — версія, сумісна з Vite у проєкті.
- npm.
- Git.

### 1. Клонування репозиторію

```bash
git clone https://github.com/0DarkDante/project_DevTeam05.git
```

### 2. Перехід у директорію проєкту

```bash
cd project_DevTeam05
```

### 3. Встановлення залежностей

```bash
npm install
```

### 4. Запуск локального сервера

```bash
npm run dev
```

Після запуску відкрийте адресу, яку виведе Vite у терміналі (зазвичай
`http://localhost:5173/`).

## 📦 Збірка проєкту

Для створення production-збірки виконайте:

```bash
npm run build
```

Готові файли будуть згенеровані в директорії `dist/`.

Для локального перегляду зібраної версії:

```bash
npm run preview
```

Для розгортання проєкту можна використовувати статичний хостинг із підтримкою
Vite-збірок.
